# Team 032 — Milestone 2 Frontend Prototype

## Run locally
1. Unzip this package.
2. Open the `frontend` folder.
3. Open `index.html` in Chrome, Edge, Firefox, or another modern browser.
4. Use the navigation to move between Dashboard, My Connection, Requests, Profile, and Coordinator.

No package installation or build step is required.

## Pages
- `index.html`: student dashboard
- `connections.html`: assigned mentor connection, reflecting client-mediated matching
- `requests.html`: request status and next steps
- `profile.html`: sample mentor profile editor
- `admin.html`: coordinator dashboard
- `styles.css`: shared responsive styles
- `screenshots/`: static design mockups included in the Milestone 2 package

## Limitations
This is a static UI prototype, not a production-ready app. The content is sample data. No backend, API, database, authentication, authorization, notifications, or persistent storage is connected. The profile form only displays a demo confirmation. Replace mockups with actual browser screenshots after implementation and testing.

## Git workflow
Create a feature branch for each user story, open a GitHub Issue, link each pull request to the issue, tag the assigned code reviewer, address comments, and merge only after review. Do not push directly to `main`.
