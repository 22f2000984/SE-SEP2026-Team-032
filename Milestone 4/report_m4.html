1. What Sprint 2 delivers

Sprint 2 completes the mentoring journey on top of the Sprint 1 backend: students ask for a mentor, both sides are introduced by email when a match is confirmed, weekly check-ins follow the mentorship, an admin review queue keeps a person in charge, and two AI features support the admin. The Vue frontend uses the backend for all of it. The application has 51 API operations (23 new in Sprint 2), 151 pytest tests and 56 frontend tests, all passing.

2.4 Error handling

Every error has the same body {"error": "message"}. 400: invalid input. 401: not logged in. 403: wrong role or wrong job secret. 404: not found, including another person's check-in or match. 409: the request conflicts with the state (answering twice, a check-in that is not due, feedback on a proposed match). 503: the reminder job is not switched on. A failure of OpenAI or Brevo never becomes an error for the user: the rules are used, or the email is logged as failed.

3. Design

PartJob
routes/Thin functions: auth, profiles, admin, matches, feedback, checkins, notifications, quiz, jobs
services/checkins, reminders, pulse_reviewWeekly rows for every active match, due and overdue states, review and reminders
services/smart_match, ai60% text fit (AI or shared keywords) + 40% rule score; one function talks to OpenAI
services/emailerSends through Brevo, writes the email log and an in-app notification
services/quiz, readiness, analyticsLevel quiz, profile checklist, dashboard numbers
frontend services/remote.jsThe one place that maps API names to the names the pages use

Human in the loop. The AI never changes a match. In the Pulse review the rules always run and the AI may only make a verdict stricter, so it cannot hide a low rating. Flagged answers and unanswered overdue check-ins wait in the admin queue until the admin marks them reviewed. Smart Match only recommends; the admin proposes and both people must accept.

Mentorship Pulse timing. When a match is confirmed, one check-in per week is created for the student and the mentor (1 month = 4 weeks, 3 months = 12, 6 months = 24). A check-in is due on its date, overdue two days later, and each person is reminded once.

Level quiz. Five questions about experience in one topic give beginner (0 to 3 points), intermediate (4 to 7) or advanced (8 to 10). It is a self-assessment, not a knowledge test. The level is shown to the admin and given to Smart Match.

Security. Role checks run on the server for every route, passwords are hashed, keys are only environment variables, the reminder job needs a secret, and the database tables are closed to Supabase's public API by row-level security.
