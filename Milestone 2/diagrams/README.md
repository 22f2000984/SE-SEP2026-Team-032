# Diagrams
`make_diagrams.py` generates `er_diagram.svg` and `class_diagram.svg`. Edit the script and run `python3 make_diagrams.py` to change them.
PNG export (Chrome headless): `"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" --headless --hide-scrollbars --screenshot=er_diagram.png --window-size=1840,1190 file://$PWD/er_diagram.svg` (class diagram: window size 1960,1420).
